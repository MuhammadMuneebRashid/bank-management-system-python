# Bank Management System

A simple Bank Management System built in Python using functions and file handling.

## Features
- Create a new account
- Deposit money
- Withdraw money
- Check account balance
- View all accounts
- File-based data storage
- Input validation and balance checking
- Exit option

## Technologies Used
- Python
- Functions
- File Handling
- While Loop
- Conditional Statements
- OS Module

## How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Run the Python file:
   bash
   python bank_management.py
   

## Concepts Used
- Functions
- File Handling (r, w, a)
- with open()
- split()
- strip()
- Lists
- Loops and Conditionals
- os.path.exists()
